# Сервис поиска специалистов по ремонту

Приложение для просмотра каталога специалистов по ремонту и связанных с ними заявок. Проект сохраняет консольную версию и предоставляет веб-интерфейс на Django. Предметные объекты и данные читаются из существующих Python-моделей и JSON-файлов `data/`.

## Реализованные возможности

- каталог специалистов с сортировкой по ставке из SQLite;
- подбор специалистов по специализации и максимальной ставке;
- страница отдельного специалиста;
- список заявок с датой и статусом из SQLite;
- карточка заявки со связанными клиентом, специалистом, услугой и расчётом ориентировочной стоимости;
- страница статистики количества заявок по статусам и специалистам;
- страницы 404 для несуществующих ID;
- консольное добавление клиентов, специалистов и услуг, создание и отмена заявок;
- загрузка и сохранение данных через JSON-хранилище;
- общий базовый Django-шаблон и наследование шаблонов;
- включаемые шаблоны навигации, карточек специалистов и статусов заявок;
- передача объектов из view в шаблоны через контекст, циклы, условия и фильтры DTL;
- именованные маршруты с пространствами имён и ссылки через `{% url %}`;
- собственные CSS, JavaScript и SVG-логотип через Django static files;
- адаптивная базовая вёрстка Bootstrap 5.3.

Django-представления читают данные из SQLite через стандартный модуль `sqlite3`; JSON-файлы используются как исходные данные для импорта. Django ORM не используется. Создание и редактирование данных через веб-формы не реализованы. Консольное приложение и JSON-хранилище сохранены.

## Веб-маршруты

| URL | Страница |
| --- | --- |
| `/` | Главная |
| `/specialists/` | Каталог специалистов |
| `/specialists/<specialist_id>/` | Карточка специалиста (данные карточки пока берутся из JSON) |
| `/specialists/search/` | Подбор по специализации и максимальной ставке из SQLite |
| `/requests/` | Список заявок |
| `/requests/<request_id>/` | Карточка заявки |
| `/requests/statistics/` | Статистика заявок из SQLite |
| `/admin/` | Стандартная административная зона Django |

## База данных SQLite

Схема находится в `sql/schema.sql`. Таблицы: `clients(id INTEGER PRIMARY KEY, name TEXT, phone TEXT)`, `specialists(id INTEGER PRIMARY KEY, name TEXT, specialization TEXT, rate REAL)`, `services(id INTEGER PRIMARY KEY, name TEXT, required_specialization TEXT, hours REAL)`, `repair_requests(id INTEGER PRIMARY KEY, client_id, specialist_id, service_id, request_date TEXT, is_cancelled INTEGER)`. Внешние ключи заявки ссылаются на клиента, специалиста и услугу; ограничения `NOT NULL`, `CHECK` и включённый `PRAGMA foreign_keys` поддерживают целостность данных.

Модуль `db/database.py` открывает `data/repair_service.sqlite3`; `db/import_json.py` создаёт таблицы по схеме и импортирует JSON. Проверенные запросы выборки, фильтрации, соединений, агрегирования и группировки сохранены в `sql/queries.sql`. Представления получают именованные строки `sqlite3.Row` из базы и передают их шаблонам. Каталог специалистов, поиск, список заявок и статистика используют SQLite; карточки специалиста и заявки пока загружаются из существующей JSON-модели.

## Структура проекта

- `repair_service/` — конфигурация Django, корневые URL, WSGI и ASGI;
- `homepage/` — главная страница, статические CSS, JS и логотип;
- `specialists/` — страницы каталога и карточки специалиста;
- `repair_requests/` — страницы списка и карточки заявки;
- `templates/` — базовый шаблон и общий фрагмент навигации;
- `models/`, `storage.py`, `data/` — предметная модель и JSON-хранилище;
- `db/database.py`, `db/import_json.py` — подключение SQLite и импорт JSON;
- `sql/schema.sql`, `sql/queries.sql` — схема БД и SQL-запросы;
- `main.py` — консольный интерфейс;
- `tests/` — тесты моделей и хранилища;
- `manage.py` — команды Django.

## Установка и запуск

Требуется Python 3.10 или новее.

```text
python -m venv .venv
```

В Windows активируйте окружение:

```text
.venv\Scripts\activate
```

Установите зависимости и запустите веб-приложение:

```text
pip install -r requirements.txt
python -m db.import_json
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/`. Консольная версия запускается командой `python main.py`.

База SQLite содержит таблицы `clients`, `specialists`, `services` и `repair_requests`. Чтобы повторно загрузить её из актуальных JSON-файлов, перед запуском сайта выполните `python -m db.import_json`.
