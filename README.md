# Сервис поиска специалистов по ремонту

## Назначение

Приложение предназначено для поиска специалистов по ремонту
(сантехников, электриков, мастеров отделочных работ) и оформления
заявок на выполнение работ. Сервис помогает клиенту быстро найти
подходящего исполнителя, а специалисту — получать заказы.

## Целевая аудитория

- Владельцы квартир и домов, которым требуется ремонт.
- Специалисты по ремонту, ищущие заказы.
- Небольшие ремонтные бригады и частные мастера.

## Предметная область

Оказание бытовых и ремонтных услуг. Клиент оставляет заявку
с описанием проблемы, выбирает услугу и специалиста. Специалист
принимает заявку и выполняет работу.

## Основные сущности

- Клиент — пользователь, оставляющий заявку.
- Специалист — исполнитель работ.
- Услуга — вид работ (сантехника, электрика, отделка).
- Заявка — обращение клиента на выполнение услуги.

## Основные функции

- Регистрация и просмотр клиентов.
- Просмотр списка специалистов и их специализаций.
- Просмотр каталога услуг.
- Создание заявки клиентом на выбранную услугу.
- Проверка возможности назначения специалиста на заявку.
- Расчёт предварительной стоимости заявки.

## План развития

На следующих этапах планируется:

- разработка веб-приложения на Django;
- подключение базы данных (PostgreSQL);
- реализация пользователей и аутентификации;
- разработка REST API;
- контейнеризация приложения в Docker;
- настройка CI/CD.
